# 管理工作台 UI 与交互实施计划

**目标**　让管理员在笔记本首屏读到工作数据和最近操作，让普通用户可以快速返回有权访问的功能。键盘用户可以从登录一路操作到编辑完成。

**实现方式**　使用现有 Vue 3、Pinia、Vue Router、Antdv Next、ECharts 和 CSS 变量。首页读取已有用户、角色、日志与菜单数据。使用项目各自的权限和数据状态决定显示内容。沿用 AN 标志、细网格和当前主题色。

| 顺序 | 交付项 | 实施位置 | 验收方法 |
| --- | --- | --- | --- |
| 1 | 工作台与销售示例 | `src/views/dashboard/`、`src/views/examples/`、`src/router/routes.ts`、`src/components/Pro/ProStatCard/` | 在 1440×900 的展开侧栏布局里，观察趋势和最近记录同时出现在首屏。在 390×844 下使用双列指标，首屏露出趋势。检查日志入口、快捷入口和示例的来源说明。 |
| 2 | 可用键盘的登录流程 | `src/views/login/index.vue`、`src/components/Captcha/src/SliderCaptcha.vue` | 在本地 Mock 环境选择管理员或普通用户，用键盘或单点触控完成等价验证，检查验证状态和登录反馈。检验正式构建的入口与表单。 |
| 3 | 用户表格与保存反馈 | `src/views/system/user/index.vue`、`src/components/Pro/ProTable/` | 默认可看到身份、角色和状态。展开可查看联系方式。“编辑”直接可用，“删除”在更多菜单并需确认。筛选后修改角色，检查页码、条件、焦点和更新提示。 |
| 4 | 动效、可读性与 AI 演示 | `src/components/Layout/`、`src/components/Pro/ProChart/`、`src/assets/styles/`、`src/stores/`、`src/locales/` | 标签指示条跟随选中项，默认页面轻淡入。减少动态效果时停用位移、图表动画和装饰循环。浅深主题分别校验正文与状态文字。只有演示构建能使用明确标识的模拟助手。 |

## 执行细节

1. 首页按实际内容宽度排版，去掉欢迎光球和静态指标上浮。读取当前用户允许访问的资源，对加载失败、无数据和无权限分别处理。快捷入口依据可见菜单过滤收藏与最近访问，排除首页自身。把有明确周期、单位和互斥分类的销售数据留在独立示例。
2. 将演示身份移至凭据上方，简化品牌文案，并把操作提示放在对应控件旁。沿用现有登录接口，保持鼠标拖动可用，同时补足键盘和单点操作、状态告知和失败后的恢复。
3. 让表格副标题展示已提交筛选和结果数，联系方式按需查看。保存成功后只刷新当前结果，定位原行。记录已离开当前筛选结果时，将焦点放回可用控件并说明结果。
4. 复用标签组件的指示条和主题切换能力。为文字定义独立的辅助色和状态色。用户自己选择的页面动画继续生效，系统减少动态效果设置优先。演示助手共用构建开关，检查已保存的旧设置。
5. 在本地隔离的 Mock 数据中完成端到端写入。按 `npm run test:unit:run`、`npm run type-check`、`npm run lint`、`npm run build`、`npm run test:e2e` 验证。以浏览器测量记录布局、颜色和实际通过的流程。
